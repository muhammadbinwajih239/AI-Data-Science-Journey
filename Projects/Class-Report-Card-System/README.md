# Class Report Card System

A Python program that collects student records and generates a full report — built as a combined project applying everything learned from Classes 1–9 of my AI & Data Science course.

## What It Does

- Takes the number of students and collects each student's name and marks
- Counts the number of vowels in each student's name
- Assigns a grade (A+, A, B, C, or Fail) based on marks
- Tracks the highest and lowest marks across all students
- Calculates total and average marks
- Counts how many students passed and failed

## Concepts Used

- Loops and nested loops
- Nested if-elif-else conditions
- String iteration
- Accumulator and counter patterns
- Dynamic tracking of highest/lowest values

## How to Run

"""
python report_card.py
"""

You'll be prompted to enter the number of students, then each student's name and marks in turn.
